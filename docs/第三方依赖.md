# Windows 便携包的第三方依赖

应用源码采用 MIT，角色和气泡使用单独的美术许可；这些许可不覆盖下列运行库。

- Python 3.13.2：Python Software Foundation License，文本随包保存在 `LICENSES/Python.txt`。源码：https://www.python.org/ftp/python/3.13.2/Python-3.13.2.tar.xz
- PySide6 / Shiboken 6.11.2 与所需 Qt 6.11.2 动态库：本包按 LGPL v3 分发，无本地修改。许可证见 `LICENSES/LGPL-3.0-only.txt`、`LICENSES/GPL-3.0-only.txt`；包中保留发行方附带的可选商业许可说明。
- PyInstaller 6.20.0 引导程序：GPL v2 或更新版本，带允许分发所生成应用的特殊例外，原文见 `LICENSES/PyInstaller/COPYING.txt`。源码：https://github.com/pyinstaller/pyinstaller/tree/v6.20.0
- Python 使用的 OpenSSL 3.0.15：Apache License 2.0，原文见 `LICENSES/OpenSSL-3.0.15.txt`。源码：https://github.com/openssl/openssl/tree/openssl-3.0.15
- Qt 随带的 Mesa 软件 OpenGL 运行库：保留原发行二进制，许可及版权说明见 `LICENSES/Mesa-license.html`，上游源码：https://gitlab.freedesktop.org/mesa/mesa

Qt / PySide6 的对应版本源码与第三方版权说明：

- https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.11.2-src/
- https://github.com/qt/pyside-setup/tree/v6.11.2
- https://github.com/qt/qtbase/tree/v6.11.2

Qt 动态库及插件位于 `_internal/PySide6/`。用户可以替换兼容版本的动态库，也可以用公开的应用源码重新构建；允许为调试所修改 LGPL 库而进行必要的逆向工程。各运行库自身携带的第三方组件仍遵循其对应源码中的版权和许可说明。
