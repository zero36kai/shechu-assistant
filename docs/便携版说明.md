# 社畜小助手便携版

1. 下载 Releases 中的 `shechu-assistant-v2.0.1-windows-x64.zip`，完整解压到有写入权限的文件夹。
2. 双击 `ShechuAssistant.exe` 或 `启动社畜小助手.bat`，打开面板并启用心跳。不需要安装 Python。
3. 关闭面板后，程序仍在托盘运行。托盘菜单可显示提醒、查看历史或退出。请保留旁边的 `_internal` 文件夹。

适用 Windows 10/11 x64。设置和记录写入 EXE 旁的 `data/`，移动整个文件夹即可一起迁移。

「喝好了」「提肛了」分别保存打卡，再次点击可撤销。选好后点「记录」收起提醒；只保留已点选项目。「稍后」收起并按设置延后提醒，默认 5 分钟。两个按钮均不会打开面板。提醒大小在面板的「角色与外观」中调整。

安装登录自启：双击 `install_startup.bat`；取消：双击 `remove_startup.bat`。这两个可选脚本需要 PowerShell 7（`pwsh`），日常双击 EXE 不需要。移动文件夹后重新设置自启。

升级时先从旧版托盘选择「退出」，完整备份旧版 `data/`，再将它复制到新版 EXE 旁，最后启动新版。请勿在新旧两份目录同时运行同一套日常记录。

源码在同一 Release 的 `Source code (zip)` / `Source code (tar.gz)`，以及 `shechu-assistant-v2.0.1-source.zip`。源码包需按 README 配置 Python 环境。
