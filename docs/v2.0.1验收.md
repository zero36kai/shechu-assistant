日期：2026-11-03。环境：Windows 11 专业版 10.0.26300、Python 3.13.2、PySide6 6.11.2。

## 交互

- 「喝好了」「提肛了」分别即时保存，再次点击撤销；「记录」只保留已点选项目并收起，不打开面板、不补记未选项。
- 「稍后」立即收起，保留本轮已选项目，到设置的延后时间后重新出现。按钮固定显示「稍后」，分钟数放在悬停提示中。
- 两个底部按钮基准尺寸为 99×30，字号与打卡按钮一致，随角色整体缩放。
- 气泡移除 ＋ / −，角色滚轮不改变大小；面板「角色与外观」滑块保存尺寸。
- 保留工具窗口、不占任务栏、自动与手动恢复最小化提醒的修复。
